# Bheema Interiors - Professional Interior Design Website

A modern, responsive interior design website built with HTML, CSS, and JavaScript. Perfect for showcasing interior design projects, services, and connecting with clients.

## Features

### 🎨 Design & Layout
- **Responsive Design**: Fully responsive and mobile-friendly layout
- **Modern UI**: Clean, professional design with smooth animations
- **Color Scheme**: Professional color palette with primary, secondary, and accent colors
- **Typography**: Modern font with excellent readability

### 📱 Sections

1. **Navigation Bar**
   - Sticky navbar with smooth scrolling
   - Mobile hamburger menu for smaller screens
   - Active link highlighting

2. **Hero Section**
   - Eye-catching banner with call-to-action button
   - Gradient background
   - Animated text elements

3. **Services Section**
   - 6 main services displayed in a grid
   - Hover effects on service cards
   - Icons for visual appeal

4. **Gallery Section**
   - Portfolio showcase with 6 project images
   - Hover overlay effects
   - Clickable lightbox for full-size image viewing
   - Responsive grid layout

5. **About Section**
   - Company information
   - Statistics/metrics display with counter animation
   - Professional description

6. **Contact Section**
   - Contact information (address, phone, email, hours)
   - Fully functional contact form
   - Form validation

7. **Footer**
   - Quick links
   - Social media links
   - Copyright information
   - Multi-column responsive layout

### ✨ Interactive Features

- **Smooth Scrolling**: All navigation links use smooth scroll behavior
- **Hamburger Menu**: Mobile-responsive navigation menu
- **Form Validation**: Contact form with basic validation
- **Scroll Animations**: Elements animate into view as you scroll
- **Counter Animation**: Statistics numbers animate when scrolled into view
- **Lightbox Gallery**: Click gallery images to view full-size
- **Scroll-to-Top Button**: Appears when scrolling down, returns to top smoothly
- **Dynamic Navbar**: Shadow effect changes based on scroll position
- **Hover Effects**: Interactive cards and buttons with smooth transitions

### 🎯 Browser Compatibility

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/kondavinodgoud/BheemaInteriors.git
   cd BheemaInteriors
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

## Customization

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #e74c3c;
    --accent-color: #3498db;
    --light-gray: #ecf0f1;
    --dark-gray: #34495e;
    --white: #ffffff;
}
```

### Content
Update the following in `index.html`:
- Company name and branding
- Services descriptions
- Gallery images
- Contact information
- Social media links

### Contact Information
Update the contact details:
- Address
- Phone number
- Email
- Business hours
